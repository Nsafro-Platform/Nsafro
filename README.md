# Nsafro

### 1) the command to create a new branch that contains the new feature 
```bash
git checkout -b "feature/SCRUM-28-paiement-reservation"
```

### 2) the command to push an empty commit to the github to transform the task from **Todo** to **In Progress**
```bash
git commit --allow-empty -m "SCRUM-28 : Enitialiser la tache de  Paiement echelonné ou partagé"
```

### 3) the command to send the changes to the remote repo  
```bash
git push origin feature/SCRUM-28-paiement-reservation
```

### 4) the command to push an empty commit to the github to transform the task from <u> In Progress </u> to <u> In Review </u>
```bash
git commit -m "SCRUM-28 : Paiement echelonné ou partagé"
```
